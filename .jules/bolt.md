## 2024-11-10 - FileSystemCollector I/O Optimization
**Learning:** In C#, using StreamWriter with the default buffer size (4KB) for high-frequency small writes (like writing file metadata rows one by one) during a deep file system enumeration is significantly slower than using a larger buffer (e.g., 64KB) because it results in frequent disk flushes and I/O context switching overhead. Writing thousands of lines sequentially as strings with `await WriteLineAsync()` over strings generated by interpolation is fast, but I/O latency adds up when unbuffered.
**Action:** When performing high-volume writes line-by-line during disk enumeration, initialize `StreamWriter` with an increased buffer size (e.g., 65536 bytes) to dramatically reduce I/O bottlenecks.
